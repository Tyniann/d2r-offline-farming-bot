# D2R Offline Farming Bot

Dieses Glossar legt die fachliche Sprache für Farming-Abläufe fest. Es trennt benannte Farming-Ziele, konkrete Wegaufzeichnungen und deren Ausführung eindeutig voneinander.

## Farming-Ablauf

**Route**:
Ein benannter Eintrag einer Queue, etwa Gräfin oder Kuh-Level. Eine Route kann eine oder mehrere veröffentlichte Routenaufzeichnungen voraussetzen.
_Vermeiden_: Run

**Routenaufzeichnung**:
Eine konkrete aufgezeichnete und veröffentlichte Wegstrecke, die der Bot zur Navigation abspielt.
_Vermeiden_: Route, wenn ausdrücklich die einzelne Aufzeichnung gemeint ist

**Queue**:
Eine sortierte Sammlung von Routen.
_Vermeiden_: Run-Liste

**Routenausführung**:
Ein Startversuch einer Route; auch ein Wiederholungsversuch ist eine neue Routenausführung.
_Vermeiden_: Run

**Durchlauf**:
Eine vollständige Wiedergabe der Queue.
_Vermeiden_: Run, Queue-Wiederholung

**Session**:
Der gesamte zusammenhängende Farming-Zeitraum, der mehrere Durchläufe und Routenausführungen enthalten kann.
_Vermeiden_: Run
